# Bank Management System – Project 2 Extension

A console-based Bank Management System developed using C++.

This project is an extension of a previous Client Management System. It adds banking transaction features, allowing users to manage client accounts and perform basic financial operations.

Features

1. Client Management

- Display all clients.
- Add new clients.
- Delete existing clients.
- Update client information.
- Search for a client using their account number.

2. Banking Transactions

- Deposit: Add money to a client's account balance.
- Withdraw: Withdraw money from a client's account balance.
- Total Balances: Display all client balances and calculate the total balance of all accounts.

3. File Handling

- Load client data from a text file.
- Save new client records.
- Update stored client information.
- Preserve client data between program executions.

Technologies & Concepts

- C++
- Structures ("struct")
- Enumerations ("enum")
- Functions
- Vectors ("vector")
- File Handling ("fstream")
- String Manipulation
- Loops and Conditional Statements
- References
- Switch Statements

Data Storage

Client records are stored in a text file named "Clients.txt".

Each client record contains:

- Account Number
- PIN Code
- Client Name
- Phone Number
- Account Balance

How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE such as Visual Studio.
3. Build and run the project.
4. Follow the console menu to manage clients and perform transactions.

Note: The project uses a local text file for data storage. Make sure "Clients.txt" is available in the program's working directory.

Project Purpose

The main purpose of this project is to practice applying fundamental C++ concepts in a more integrated program.

It focuses on organizing code into functions, managing data structures, handling files, and connecting different program components to implement a practical application.
